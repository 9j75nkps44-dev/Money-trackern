MY MONEY TRACKER — WEB APP V1

This is the proper web-app/PWA version for iPad.

Features:
- Dashboard: income, expenses, savings, remaining
- Add Expense / Income / Savings
- Savings goals and progress
- Transactions
- Monthly report
- Monthly CSV export
- Print / Save as PDF
- iPad responsive layout
- Home-screen/PWA metadata
- Local browser storage

IMPORTANT:
The app is ready to host, but a live web address is required before iPad can use it like a normal web app.

Recommended hosting options:
1. GitHub Pages: upload these files to a repository and enable Pages.
2. Cloudflare Pages: upload the folder using Direct Upload.

After it is live:
Safari -> open the URL -> Share -> Add to Home Screen.

Data note:
V1 stores data locally in the browser on the device. Do not treat the local browser copy as a cloud backup. Export monthly CSV/PDF until cloud sync is added.
